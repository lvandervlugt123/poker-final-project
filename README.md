# poker-final-project

Overview

This project is a browser-based poker game built using HTML, CSS, and JavaScript. The goal of the project was to create an interactive card game that simulates a simplified poker experience between a player and a dealer. The application focuses on core game logic, user interaction, and clean visual design.

Features
Standard 52-card deck generation and shuffling
Card dealing system for player and dealer
Basic poker hand evaluation (pair, two pair, three of a kind, high card)
Winner determination based on hand rankings
Interactive buttons for dealing, revealing cards, and starting a new round
Hidden dealer card mechanic for suspense
Simple betting system with balance tracking
Persistent data using local storage
Technologies Used
HTML for structure
CSS for styling and layout
JavaScript for game logic and interactivity
Local Storage API for saving player progress
How It Works

When the game begins, a shuffled deck is generated and cards are dealt to both the player and the dealer. The player can interact with the game using buttons to control the flow, including revealing the dealer’s hand. Each round, both hands are evaluated and compared to determine the winner. The player’s balance updates based on the outcome.

Purpose of the Project

The purpose of this project was to apply fundamental web development concepts, including:

DOM manipulation
Event handling
Game logic implementation
Data persistence in the browser

This project also emphasizes structuring code in a way that supports incremental development and scalability.

Future Improvements
