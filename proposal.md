Project Overview

The goal of this project is to develop an interactive poker game that runs entirely in the browser using HTML, CSS, and JavaScript. The game will simulate a simplified version of poker between a player and a computer-controlled dealer. Users will be able to play multiple rounds, interact with the game through buttons, and track their performance over time.

Core Features
Generation and shuffling of a standard 52-card deck
Dealing cards to both the player and the dealer
Display of cards in a structured game layout
Basic hand evaluation (high card, pair, two pair, three of a kind)
Winner determination based on hand rankings
Interactive controls for dealing, revealing cards, and restarting the game
Hidden dealer card mechanic to create suspense
Simple betting system with a running balance
Persistent storage of player balance using local storage
